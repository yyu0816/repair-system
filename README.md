# 校園設備報修系統

本專案將原有的校園設備報修系統（Repair Demo）軟體規格書重新梳理，轉化為一套可供 AI Agent 理解、遵循並協作的標準化工作規範與 Skill。

---

## 如何使用

當你（或團隊成員）要使用這套文件讓 AI Agent 協作開發或維護本專案時，請遵循以下步驟：

1. **初始化上下文**：在下達指令前，先引導 AI 讀取 `AGENTS.md` 與 `software-spec.md`，了解系統架構與功能。
2. **確認安全邊界**：讓 AI 依照 `AGENTS.md` 的規範進行開發順序對齊，確保不違反專案限制。
3. **載入特定 Skill**：若要處理特定邏輯（如狀態切換驗證），可指示 AI 參照 `skills/repair-flow/SKILL.md`。
4. **對照驗收**：開發完成後，對照 `software-spec.md` 中的驗收條件（AC-01 ~ AC-09）進行測試。
